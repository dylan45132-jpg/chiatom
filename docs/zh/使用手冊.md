## 1. 介面概覽

```
┌─────────────────────────────────────────────────┐
│  工具列（Toolbar）                                │
├────────────┬────────────────────────────────────┤
│            │                                    │
│  側邊欄    │         編輯畫布（Canvas）           │
│  (Sidebar) │                                    │
│            │    ┌─────────────────────┐         │
│  頁面列表  │    │                     │         │
│            │    │   A4 頁面           │         │
│  [＋] 新增 │    │                     │         │
│            │    └─────────────────────┘         │
│            │                                    │
└────────────┴────────────────────────────────────┘
```

**工具列**：文件標題編輯、開啟、儲存、匯出 HTML、主題設定。

**側邊欄**：頁面列表，支援拖曳排序、右鍵選單（插入、複製、刪除）。

**編輯畫布**：A4 頁面直接呈現，所見即所得。

## 2. 文件管理

### 新建文件

啟動應用時，畫面會顯示引導畫面。點擊左側「＋」新增第一個頁面，即開始新文件。

### 儲存

點擊工具列「儲存」，第一次儲存會跳出對話框，選擇儲存位置。

存檔格式為 `.handout`，這是一個包含文件資料與圖片資產的打包檔案。

> 之後的儲存會直接覆蓋同一個檔案，不會再跳出對話框。若要另存新檔，請關閉應用重新開啟再儲存。

### 開啟

點擊工具列「開啟」，選取 `.handout` 檔案。

### 文件標題

點擊工具列左側的標題文字，直接編輯。標題不出現在講義頁面中，僅用於存檔檔名與工具列顯示。

## 3. 頁面管理

### 新增頁面

點擊側邊欄底部的「＋」按鈕，在最後新增一個空白頁面。

### 切換頁面

點擊側邊欄的頁面項目，切換到該頁面。

### 頁面排序

在側邊欄拖曳頁面項目，調整順序。

### 右鍵選單

在側邊欄的頁面項目上按右鍵，可以：
- **插入頁面**：在此頁面之後插入新頁面
- **複製頁面**：複製此頁面的內容到新頁面
- **刪除頁面**：刪除此頁面（至少保留一頁）

### 頁面標題

側邊欄顯示的頁面標題（預設為「頁面 1」、「頁面 2」……）不出現在講義中，僅用於識別。

### 頁面溢出警示

當頁面內容超出 A4 高度時，頁面底部會出現紅色警示線和提示文字「內容超出 A4 範圍」。

這個狀態不會自動處理，你需要手動刪減內容，或將後面的區塊移到下一頁。

## 4. 區塊操作

### 插入區塊

在頁面內任意位置按 `/`，叫出區塊選單，選擇要插入的區塊類型。

### 基本區塊類型

| 區塊 | 說明 |
|---|---|
| 大標題（h1） | 頁面主標題 |
| 中標題（h2） | 段落標題 |
| 小標題（h3） | 細分標題 |
| 段落 | 一般文字 |
| 無序清單 | 項目符號列表 |
| 有序清單 | 編號列表 |
| 引用 | 引用文字區塊 |
| 表格 | 自訂欄列數的表格 |
| 分隔線 | 水平分隔線 |
| 圖片 | 圖片佔位區塊 |
| 行內方程式 | LaTeX inline 方程式 |
| 區塊方程式 | LaTeX block 方程式 |

### 複合區塊

由主題定義的自訂區塊，例如「重點摘要」、「核心目標」等。不同主題提供不同的複合區塊，同樣透過 `/` 選單插入。

換主題後，若目前主題不支援某個複合區塊，該區塊會顯示黃色警示邊框，內容仍可正常編輯。

### 區塊排序

在區塊左側出現的拖曳把手，可以拖曳調整區塊順序。

### 文字格式

選取文字後，會出現浮動工具列，提供：粗體、斜體、底線、行內程式碼。

### 表格操作

插入表格時，會出現設定面板，讓你選擇欄數和列數。插入後，選取表格會在浮動工具列出現表格操作選項（新增列、刪除列等）。

## 5. 主題系統

### 什麼是主題

主題控制講義的視覺樣式，包含字型、顏色、間距、各區塊的外觀。主題只影響 `.page` 容器內的內容，不影響編輯器本身的介面。

### 內建主題

點擊工具列「主題」→「內建主題」，目前提供三套：

| 主題 | 風格 |
|---|---|
| Slate | 石板灰調，細邊線，理工講義 |
| Washi | 暖米白，和紙質感，人文課程 |
| Moss | 低飽和草綠 accent，自然沉穩，通用型 |

### 匯入自訂主題

點擊工具列「主題」→「資料夾匯入」，選取包含 `theme.css` 和 `theme.json` 的主題資料夾。

### 貼上 CSS

點擊工具列「主題」→「貼上 CSS」，直接貼入 CSS 文字，快速套用樣式（無複合區塊）。

### 重設主題

點擊工具列「主題」→「重設為預設主題」，清除目前主題。

## 6. 方程式

### 插入方程式

按 `/` 選單，選擇「行內方程式」或「區塊方程式」，插入一個預設方程式。

- **行內方程式**：嵌入在段落文字中
- **區塊方程式**：獨立一行，置中顯示

### 編輯方程式

點擊方程式，會彈出編輯 Modal，包含：

- **預覽**：即時渲染結果，語法錯誤時顯示錯誤訊息
- **LaTeX 輸入框**：輸入或修改 LaTeX 語法
- **常用語法片段**：點擊快速插入常用語法

確認後更新方程式；取消則不做任何變更。

### 常用 LaTeX 語法參考

| 語法 | 效果 |
|---|---|
| `E=mc^2` | 上標 |
| `x_{n}` | 下標 |
| `\frac{a}{b}` | 分數 |
| `\sqrt{x}` | 根號 |
| `\int_{a}^{b} f(x)\,dx` | 積分 |
| `\sum_{i=1}^{n}` | 求和 |
| `\alpha \beta \gamma` | 希臘字母 |

## 7. 圖片

### 插入圖片

按 `/` 選單，選擇「圖片」，插入圖片佔位區塊。點擊佔位區塊，選取本機圖片檔案（支援 PNG、JPG、GIF、WebP）。

### 圖片儲存方式

圖片以二進位格式存入 `.handout` 打包檔的 `assets/` 資料夾，不會把 base64 塞入文件 JSON，避免效能問題。

### 匯出時的圖片處理

匯出 HTML 時，圖片會自動轉換為 base64 inline，輸出的 HTML 檔案完全自給自足，不依賴任何外部檔案。

## 8. 匯出與列印

### 匯出 HTML

點擊工具列「匯出 HTML」，選擇儲存位置。輸出的 HTML 檔案包含：
- 完整的主題 CSS（inline）
- 所有圖片（base64 inline）
- KaTeX CSS 連結（若文件包含方程式）

### 列印為 PDF

用瀏覽器開啟匯出的 HTML 檔案，按 `Ctrl+P`（Windows）或 `Cmd+P`（macOS）列印。

建議設定：
- 紙張大小：A4
- 邊距：無（主題 CSS 已控制內距）
- 背景圖形：開啟（確保主題背景色正確印出）

每個頁面對應一張 A4 紙，不會自動跨頁流動。

## 9. 快捷鍵

### 編輯器快捷鍵

| 快捷鍵 | 效果 |
|---|---|
| `/` | 開啟區塊選單 |
| `Ctrl+B` | 粗體 |
| `Ctrl+I` | 斜體 |
| `Ctrl+U` | 底線 |
| `Ctrl+Z` | 復原 |
| `Ctrl+Shift+Z` | 重做 |

### Markdown 語法觸發

在段落中輸入以下語法後按空白鍵，自動轉換：

| 輸入 | 轉換為 |
|---|---|
| `#` + 空白 | 大標題（h1） |
| `##` + 空白 | 中標題（h2） |
| `###` + 空白 | 小標題（h3） |
| `-` 或 `*` + 空白 | 無序清單 |
| `1.` + 空白 | 有序清單 |
| `>` + 空白 | 引用 |
| `---` | 分隔線 |

## 10. 注意事項

**頁面不自動跨頁**

Chiatom 的設計是「你控制內容在哪一頁」，不做自動跨頁流動。當內容超出 A4 時，會出現警示，需要手動調整。

**`.handout` 格式**

`.handout` 是 Chiatom 的工作檔格式，本質是 zip 壓縮檔。不要用其他工具解壓縮後直接修改，可能導致格式損毀。

**方程式在離線環境**

匯出的 HTML 透過 CDN 載入 KaTeX 字型，在完全離線的環境下，方程式仍會顯示但字型可能 fallback 為系統字型。對列印結果影響有限。

**主題 CSS 作用域**

主題 CSS 只影響 `.page` 容器內的樣式，無法修改編輯器介面（工具列、側邊欄等）。
