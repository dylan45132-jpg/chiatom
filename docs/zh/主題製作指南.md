## 1. 主題包結構

一個主題包是一個資料夾，包含兩個檔案：

```
my-theme/
├── theme.css     # 頁面樣式（必要）
└── theme.json    # 主題資訊與複合區塊定義（可選）
```

`theme.css` 是必要檔案，`theme.json` 是可選的——沒有 `theme.json` 的主題仍然可以套用，只是沒有複合區塊。

匯入方式：Chiatom 工具列「主題」→「資料夾匯入」，選取整個主題資料夾。

## 2. theme.json 規格

```json
{
  "name": "主題名稱",
  "version": "1.0.0",
  "author": "作者名稱",
  "description": "一句話描述這套主題",
  "pageSize": "A4",
  "blocks": []
}
```

| 欄位 | 類型 | 說明 |
|---|---|---|
| `name` | string | 主題顯示名稱 |
| `version` | string | 版本號，格式自訂 |
| `author` | string | 作者（可空白） |
| `description` | string | 主題描述 |
| `pageSize` | string | 目前固定為 `"A4"` |
| `blocks` | array | 複合區塊定義，詳見第 4 節 |

## 3. theme.css 規格

### 作用域

主題 CSS 的所有樣式都必須寫在 `.page` 這個 class 的作用域內。`.page` 是每個 A4 頁面的根容器。

```css
/* ✅ 正確：限定在 .page 內 */
.page h1 { ... }
.page p { ... }

/* ❌ 錯誤：全域樣式，會影響編輯器介面 */
h1 { ... }
body { ... }
```

### 頁面容器

`.page` 本身的 `width`、`min-height`、`padding` 由編輯器控制，主題不需要設定這些。

主題可以設定 `.page` 的以下屬性：

```css
.page {
  font-family: ...;   /* 字型 */
  font-size: ...;     /* 基礎字級 */
  line-height: ...;   /* 行高 */
  color: ...;         /* 基礎文字顏色 */
  background: ...;    /* 頁面背景色 */
}
```

### 基本區塊 CSS 對應

| 區塊 | CSS 選擇器 |
|---|---|
| 大標題 | `.page h1` |
| 中標題 | `.page h2` |
| 小標題 | `.page h3` |
| 段落 | `.page p` |
| 無序清單 | `.page ul`、`.page ul li` |
| 有序清單 | `.page ol`、`.page ol li` |
| 引用 | `.page blockquote` |
| 表格 | `.page table`、`.page th`、`.page td` |
| 分隔線 | `.page hr` |
| 圖片 | `.page img` |

### 最小可用 theme.css 範例

```css
.page {
  font-family: 'Noto Sans TC', sans-serif;
  font-size: 13px;
  line-height: 1.75;
  color: #1a1a1a;
  background: #ffffff;
}

.page h1 {
  font-size: 20px;
  font-weight: 700;
  margin: 0 0 20px 0;
  padding-bottom: 8px;
  border-bottom: 2px solid #1a1a1a;
}

.page h2 {
  font-size: 15px;
  font-weight: 700;
  margin: 24px 0 10px 0;
}

.page h3 {
  font-size: 13px;
  font-weight: 700;
  margin: 16px 0 6px 0;
}

.page p {
  margin: 0 0 10px 0;
}

.page ul,
.page ol {
  margin: 0 0 10px 0;
  padding-left: 20px;
}

.page li {
  margin-bottom: 4px;
}

.page blockquote {
  border-left: 3px solid #cccccc;
  margin: 12px 0;
  padding: 6px 16px;
  color: #666666;
}

.page table {
  width: 100%;
  border-collapse: collapse;
  margin: 12px 0;
  font-size: 12px;
}

.page th {
  background: #1a1a1a;
  color: #ffffff;
  padding: 6px 10px;
  text-align: left;
}

.page td {
  border: 1px solid #cccccc;
  padding: 5px 10px;
}

.page hr {
  border: none;
  border-top: 1px solid #cccccc;
  margin: 18px 0;
}

.page img {
  max-width: 100%;
  display: block;
  margin: 12px auto;
}
```

## 4. 複合區塊定義

複合區塊是「幾個基本區塊組合成一個語義單元」，例如「重點摘要」、「核心目標」。

### theme.json 中的定義

```json
{
  "blocks": [
    {
      "name": "重點摘要",
      "key": "summary-box",
      "icon": "📋",
      "class": "block-summary-box",
      "children": [
        { "type": "label", "placeholder": "標籤文字" },
        { "type": "ol", "placeholder": "條列重點..." }
      ]
    }
  ]
}
```

| 欄位 | 說明 |
|---|---|
| `name` | 顯示名稱，出現在 `/` 選單 |
| `key` | 唯一識別碼，英文小寫加連字號，不可重複 |
| `icon` | `/` 選單顯示的圖示（emoji 或文字） |
| `class` | 套用到 wrapper div 的 CSS class 名稱 |
| `children` | 子區塊陣列，定義內部結構 |

### children 支援的 type

| type | 說明 |
|---|---|
| `label` | 單行標籤文字 |
| `p` | 段落 |
| `ol` | 有序清單 |
| `ul` | 無序清單 |

### 對應的 theme.css 樣式

每個複合區塊需要在 `theme.css` 中定義對應的樣式：

```css
/* 對應 key: "summary-box"，class: "block-summary-box" */
.page .block-summary-box {
  border: 1px solid #cccccc;
  border-radius: 4px;
  padding: 12px 16px;
  margin: 12px 0;
  background: #f9f9f9;
}

.page .block-summary-box .block-label {
  font-size: 11px;
  font-weight: 700;
  text-transform: uppercase;
  letter-spacing: 0.05em;
  color: #666666;
  margin-bottom: 6px;
}
```

### Fallback 行為

當文件使用了某個複合區塊，但目前主題的 `theme.json` 沒有對應定義時，該區塊會顯示黃色警示邊框，內容仍可正常編輯。換回支援該區塊的主題後，樣式自動恢復。

## 5. 列印樣式

匯出 HTML 後用瀏覽器列印時，建議在 `theme.css` 加入 `@media print` 規則。

### 基本列印設定

```css
@media print {
  .page {
    /* 確保背景色和背景圖片在列印時保留 */
    -webkit-print-color-adjust: exact;
    print-color-adjust: exact;
  }
}
```

### 若主題使用深色背景

```css
@media print {
  .page {
    -webkit-print-color-adjust: exact;
    print-color-adjust: exact;
    background: #你的背景色;
  }
}
```

不需要在主題 CSS 裡處理分頁——Chiatom 的編輯器已經在全域處理每個 `.page` 的分頁行為。

## 6. 用 LLM 設計主題

Chiatom 的主題系統設計為「LLM 友善」——你可以用 ChatGPT、Claude 等工具生成主題 CSS，再直接匯入使用。

### 推薦的 prompt 結構

```
幫我設計一套 Chiatom 文件主題的 CSS。

規格：
- 所有樣式必須限定在 .page 這個 class 作用域內（例如 .page h1 { ... }）
- 不要設定 .page 的 width、min-height、padding（由編輯器控制）
- 需要覆蓋的選擇器：.page、.page h1、.page h2、.page h3、.page p、
  .page ul、.page ol、.page li、.page blockquote、.page table、
  .page th、.page td、.page hr、.page img

風格：[描述你想要的風格，例如：暗色系、學術風、日系簡約...]
主色調：[描述顏色偏好]
字型：[Noto Serif TC / Noto Sans TC / Georgia / 其他]
```

### 設計建議

- 主視覺避免使用紫色、霓虹色漸層
- 一套主題內的非中性色控制在 1–2 種
- 字級層級控制在少數幾種（h1 / h2 / h3 / 內文），字重對比優先
- 表格的 `th` 背景色和 `td` 交替色可以呼應主色調

## 7. 測試主題

### 建議測試清單

匯入主題後，建議在測試文件中驗證以下項目：

- [ ] h1、h2、h3 的視覺層級清楚
- [ ] 段落文字的可讀性（字型、字級、行高、顏色）
- [ ] 無序清單和有序清單的縮排與符號
- [ ] blockquote 的左邊線和文字顏色
- [ ] 表格的欄位對齊、邊框、交替色
- [ ] 圖片在頁面內的對齊
- [ ] 方程式（若文件有使用）的字型搭配
- [ ] 頁面背景色在編輯器中的顯示
- [ ] 匯出 HTML 後，在瀏覽器中的列印預覽結果

### 快速測試方式

1. 在 Chiatom 新增一個測試頁面
2. 用 `/` 選單逐一插入各種區塊
3. 套用主題，觀察各區塊的樣式
4. 匯出 HTML，用瀏覽器開啟並列印預覽

## 8. 範例主題

Chiatom 內建三套主題可以作為參考起點：

| 主題 | 風格 | 特色 |
|---|---|---|
| Slate | 石板灰調，理工 | h1 底線、h2 左邊線、深色表格標頭 |
| Washi | 暖米白，人文 | h1 置中、暖棕色調、柔和表格 |
| Moss | 草綠 accent，通用 | h1 左色塊、綠色 accent、清爽表格 |

內建主題的 CSS 檔案位於專案的 `src/theme/themes/` 資料夾，可以直接複製修改作為新主題的基礎。
